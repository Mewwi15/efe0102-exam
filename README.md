# ติวสอบปลายภาค EFE0102

เว็บฝึกทำข้อสอบปลายภาค วิชา EFE0102 การบริหารสถานศึกษาและการประกันคุณภาพการศึกษา (ภาคเรียนที่ 1/2569)

- **จำลองสอบ:** ปรนัย 60 ข้อ (4 ตัวเลือก) จับเวลา ส่งแล้วได้คะแนนเต็ม 25 พร้อมเฉลยและคำอธิบาย
- **ฝึกรายบท:** เลือกบทได้ ตอบแล้วเห็นเฉลยทันที บอกว่ามาจากสไลด์หน้าไหน
- **เขียนตอบ:** ซ้อมเขียนตอบสั้น แล้วเทียบกับแนวคำตอบและประเด็นให้คะแนน
- **SWOT:** จัดข้อความของโรงเรียนสมมติลงช่อง S / W / O / T พร้อมเหตุผล (2S4M / STEP) และตัวอย่างกลยุทธ์ TOWS

ไม่มีฐานข้อมูล ประวัติและคะแนนเก็บอยู่ในเบราว์เซอร์ของแต่ละคน

> ข้อสอบทุกข้อแต่งขึ้นเพื่อฝึกทบทวนจากสไลด์ประกอบการสอน ไม่ใช่ข้อสอบจริง
> ตัวสไลด์ไม่ได้อยู่ใน repo นี้ เว็บลิงก์ไปยังไฟล์ใน Google Drive ของผู้สอนแทน

## รันในเครื่อง

```bash
pnpm install
pnpm dev
```

## โครงสร้าง

| ที่อยู่ | คืออะไร |
|---|---|
| `bank/chNN.json` | คลังข้อสอบรายบท (ปรนัย + เขียนตอบ) |
| `bank/swot.json` | โจทย์ SWOT 8 ชุด |
| `bank/validate.py` | ตัวตรวจรูปแบบคลังข้อสอบ: `python3 bank/validate.py bank/*.json` |
| `sources/manifest.json` | ข้อมูลบทและลิงก์สไลด์ |
| `scripts/build-bank.mjs` | รวมคลังเป็น `src/data/bank.json` (รันเองก่อน `dev` / `build`) |

ทำด้วย Next.js + TypeScript + Tailwind CSS + Ant Design
